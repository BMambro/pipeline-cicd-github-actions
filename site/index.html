disciplinas
⚙️
DevOps

Cultura de integração entre desenvolvimento e operações, focada em entrega contínua, automação de infraestrutura e observabilidade em produção.

  • Pipelines CI/CD com GitHub Actions e GitLab CI
  • Containerização com Docker e orquestração Kubernetes
  • Infrastructure as Code com Terraform e Ansible
  • Monitoramento com Prometheus, Grafana e alertas
  • GitOps com ArgoCD e FluxCD
  • Gestão de segredos com Vault e SOPS
📊
DataOps

Aplicação das práticas DevOps para pipelines de dados: automação, testes, versionamento e entrega confiável de dados em escala.

  • Orquestração de pipelines com Apache Airflow e Prefect
  • Transformações e testes de dados com dbt
  • Qualidade de dados com Great Expectations e Soda
  • Data lineage e catalogação com DataHub e OpenMetadata
  • Lakehouse com Delta Lake, Iceberg e Apache Hudi
  • CI/CD para dados: deploy, rollback e testes automáticos
📡
Observabilidade

Visibilidade total de sistemas e pipelines através de métricas, logs e rastreamento distribuído.

  • Stack OpenTelemetry para métricas, logs e traces
  • Dashboards de SLI/SLO e error budgets
  • Alertas inteligentes com redução de ruído
  • Distributed tracing com Jaeger e Tempo
🛡️
Data Quality

Garantia de confiabilidade, consistência e completude dos dados ao longo de todo o ciclo de vida.

  • Testes unitários e de integração em modelos dbt
  • Validação de schemas e contratos de dados
  • Detecção de anomalias e data freshness checks
  • Data observability com Monte Carlo e Metaplane
